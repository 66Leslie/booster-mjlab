# Local retargeted motions

Keep locally generated motion artifacts below this directory only when a package-relative path is convenient. Git ignores the contents of this directory except for this README.

Prefer setting `MJLAB_PLAYGROUND_MOTION_ROOT` or `MJLAB_TRACKING_MOTION_FILE` to a data directory outside the source tree. See the repository's `docs/motion_data.md` for the expected layout, schema, and redistribution policy.
